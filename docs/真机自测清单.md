# 真机自测清单（iPhone）

**为什么需要你做这一步**：自动化测试能覆盖规则、AI、布局与接线，但覆盖不了三件事——
**手感（会不会误触、字看着累不累）、AI 下得有没有意思、真机上的真实行为**
（安装、离线、后台回收）。这三件只有真机能验。

大约 **6 分钟**。每项都写了「应该看到什么」；**看到别的就告诉我第几项**，
不用描述得很准，一句「第 7 项点撤销没反应」就够我定位。

地址：**https://danweizheng.github.io/castles-of-burgundy/**

---

## 1. 打开与安装

用 **Safari** 打开上面的地址 → 点分享 → **添加到主屏幕**。

- **应该看到**：图标是深色棋盘风格，名字是「勃艮第」，从主屏图标打开后**没有浏览器地址栏**，
  而且启动时先出现一张**深色带金色城堡的启动图**（而不是白屏一闪）。
- 如果图标是白底方块或名字是域名 → 告诉我（说明图标或 manifest 有问题）。

## 2. 离线就绪（第一次必须联网一次）

从主屏图标打开，**先联网完整加载一次**，滚到最底部。

- **应该看到**：页脚有一行 **「离线：已就绪」**。
- 如果显示 **「离线：正在缓存…（首次访问请保持联网片刻）」** → 等几秒再看；一直不变就告诉我。
- 如果显示 **「离线：当前环境不支持」** → 直接告诉我（说明 Service Worker 没注册上）。

## 3. 飞行模式验证离线 ⭐

确认第 2 项是「已就绪」之后：**开飞行模式** → 从主屏图标重新打开。

- **应该看到**：应用照常打开，能继续玩。
- 如果白屏、报错、或提示无法连接 → 告诉我（这是最需要确认的一项）。

## 4. 开一局、选出生点

回到联网（或保持离线都行）→ 若已有对局，点 **新局**。

- **应该看到**：弹出「选择出生点」，正文写着「官方规则：起始城堡放在你选定的深红格上……」，
  版图上有几个深红格被点亮，底部有「用推荐的中央格」按钮。
- 点一个深红格，或点「用推荐的中央格」→ 对局开始。
- 如果深红格点不动、或点完之后界面没变化 → 告诉我。

## 5. 一个完整回合

- **应该看到**：底部有 2 颗骰子。点一颗 → 仓库里若干格位被点亮。
- 点一个点亮的格位 → 板块进入你的「仓储」，且**消耗一颗骰子**。
- 再点另一颗骰子，**这时底部会出现仓储里每枚板块的效果说明**（例如
  「1. 木工坊 — 从任意编号仓库（非黑洞）取 1 枚米色建筑板块，放入仓储空位。」）。
- 点领地里的点亮格子 → 板块放下。用完两颗骰子后会出现「结束回合」。

**特别留意**：按钮会不会太小、误触？字看着累不累？点亮的地方够不够明显？
这些我没法自己判断，**任何"别扭"的感觉都值得说**。

## 6. 观察对手

点「结束回合」后轮到对手。

- **应该看到**：底部显示「对手行动中…」，对手会自己想一会儿再走（困难档约半秒一步），
  日志里出现对手的行动。
- 如果对手**卡住不动**、或**连续走了很多步不停**、或走到一半界面没反应 → 立刻告诉我
  （这是我最想抓的问题）。
- 顺便判断一下：**对手下得像不像在玩这个游戏**？（会抢你想要的板块吗？会去完成区域吗？）

## 7. 撤销 ⭐

- 走一步自己的行动 → 点 **撤销** → 应该退回上一步。
- **重点**：等对手也走过一步之后，再点 **撤销**。
  - **应该看到**：直接回到**你自己上一次决定**的时刻，而不是"按了没反应"。
  - 如果按了撤销什么都没变 → 告诉我（这是个真实修过的缺陷，想确认真的好了）。
- 连着点几次撤销：应该一步步退回开局，中途**不应该卡在"轮到对手"的状态**。

## 8. 切走再回来

走几步 → 切到别的 App（或锁屏）→ 等几秒 → 切回来。

- **应该看到**：回到刚才的局面，**最后一步也在**。
- 如果丢了一步 → 告诉我。

## 9. 杀掉应用再打开

往上滑把应用从后台划掉 → 从主屏图标重新打开。

- **应该看到**：自动恢复到刚才的局面（不会问你，直接进入）。
- 如果回到开局、或提示存档无法恢复 → 告诉我，并**把提示原文发我**。

## 10. 打完一局

一直玩到结束（想快点可以选「轻松」难度，或直接开新局随便走完）。

- **应该看到**：弹出终局面板，标题是「你赢了」或「X赢了」，下面是双方的分项明细
  （对局中得分 / 未卖货物 / 剩余银币 / 工人折算 / 知识板块 / 领地空格）。
- 点 **「先看棋盘（可再打开结果）」** → 面板收起，能看到终局棋盘；底部出现「查看结果」可以再打开。
- 如果终局面板一出来就无法关掉、只能开新局 → 告诉我（这个出口是刚加的，想确认好用）。

## 11. 横屏看一眼

把手机横过来。

- **应该看到**：界面仍然可用（棋盘变小、操作条变矮）。
- 如果元素重叠、被截断、或按钮点不到 → **横屏截图**发我。

## 12. 规则速查 → 「差异」页

点顶部的 **规则** → 切到最后一个分页 **差异**。

- **应该看到**：分六节说明「哪些数字是从规则书核实的、哪些是推断的、哪些还是占位数据」。
- **这一页请顺手核对**：最后两节提到「区域分数表是推断的（三角数）」和
  「阶段奖励中间值 8/6/4 是推断的」。**你手上有版图的话，翻到分数表看一眼**，
  如果和我写的不一样，告诉我具体数字 —— 这是目前唯一还靠推断的规则数据。

## 13. 可选：版图录入器

如果你愿意把 1 号版图录进来（这是唯一还让"数据是假的"的东西）：
打开 **https://danweizheng.github.io/castles-of-burgundy/editor.html**，
对着实物点格子，导出 JSON 发我。详见页面内的说明。

## 报告问题时，这几样信息最有用

1. **第几项**（例如"第 7 项"）
2. **截图**（iPhone 上同时按侧边键 + 音量加）
3. **机型和 iOS 版本**（设置 → 通用 → 关于本机）
4. 页脚那行**离线状态原文**（「离线：已就绪」/「正在缓存…」/「当前不支持」）
5. 如果是报错，**把错误原文发我**

不用整理得很整齐，**原始的一句描述加一张截图，比完整报告更有用**。
