# 版图照片放这里

把实物照片放进这个目录，我会通过 workflow 转发给视觉模型（`claude-opus-4-8`）转录成 JSON 数据。
我自己的模型读不了图，但这条转发通路已经实测可用（用一张自绘图标验证过）。

## 优先拍这两样（MVP 的关键路径）

### 1. 玩家版图 No. 1

基础版里 1 号版图出现 9 次（4 张双面板两面都是 1 号，No.2–9 的反面也是 1 号），
所以两人同用 1 号既公平也是常见玩法。**先只录 1 号就能打通全流程。**

需要看清的信息：

- 每个六边形格的**颜色**（深绿 / 浅绿 / 米色 / 灰 / 蓝 / 黄）
- 每个格的**数字**（1–6）
- **区域边界线**：哪几格属于同一个印刷区域（同色相邻的连通块）
- **米色城市的划分**、**浅绿牧场的划分**（通常与区域边界一致，但要确认）

拍摄建议：正面俯拍、光线均匀、手机尽量贴近。
**同一张版图分 2–4 块局部特写**，比拍一整张更容易看清数字和边界线。
局部特写请把区域的分界线也拍进去。

命名示例：`board-1-full.jpg`、`board-1-top.jpg`、`board-1-bottom.jpg`

### 2. 中央版图

- 6 个编号仓库（1–6）各自的格位**颜色**
- 每个格位上标着 **2 / 3 / 4** 中的哪一个（表示几人局启用）
- 第 6 号仓库那个**深绿（城堡）格位**在什么位置

为什么要这个：仓库格位是**印了颜色**的，所以"点数 N 能抽到什么颜色"由版图决定，不是随机的。
这会影响 AI 的判断质量。

命名示例：`central-board.jpg`、`central-depots.jpg`

  （当前代码里这些数字是臆造的占位值）
